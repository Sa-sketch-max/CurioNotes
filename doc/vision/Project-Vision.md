# CurioNotes

## Vision

CurioNotes is a modern desktop note-taking application built using Java and JavaFX.

The objective is to create a desktop application comparable to Obsidian and Notion while learning professional software engineering practices.

Unlike tutorial-based projects, every architectural decision, feature, mistake, and improvement will be documented.

The project focuses on:

- Java
- JavaFX
- Object-Oriented Programming
- Design Patterns
- Markdown
- SQLite
- Git
- Software Architecture
- Clean Code
- SOLID Principles

---

## Goals

- Build a professional portfolio project.
- Learn software architecture.
- Understand every line of code.
- Be able to explain every design decision during interviews.
- Learn debugging instead of memorizing solutions.

---
